About:

This project is a web-based calculator built using HTML, CSS, and JavaScript. It was created to practise web development and improve my understanding of how these technologies work together.

Technologies Used:

HTML — structures the calculator interface.

CSS — styles the calculator.

JavaScript — handles the calculator's functionality.

Features:

A calculator interface built with HTML and CSS.

JavaScript functionality for processing user input and calculations.

A visual layout designed for use in a web browser.

How to Run:

Clone or download this repository.

Open the project folder.

Open WEBPAGEDESIGN.html in a web browser.

What I Learned:

Structuring a web page with HTML.

Styling a user interface with CSS.

Using JavaScript to add interactivity.

Organizing files in a web development project.

Using Git and GitHub to track and publish code.
